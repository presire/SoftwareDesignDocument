# [ファイルフォーマット定義書]記載例_計測データ収集システム.xlsx の項目説明

`[ファイルフォーマット定義書]記載例_計測データ収集システム.xlsx`は、  
架空の「計測データ収集システム」が入出力する6種類のファイル・電文 (JSON / CSV / 固定長 / バイナリ / HTTP / TOML) の仕様を定義した記載例です。  

本書では、各シートに並ぶ項目が何を表すのかを簡単に説明します。  

## シート構成

| No. | シート | 内容 |
|---|---|---|
| 1 | 表紙 | 文書名・対象システム・版数などの文書情報 |
| 2 | 改訂履歴 | 版ごとの改訂内容 |
| 3 | 共通仕様 | 全ファイルに共通する用語・表記・型・日付形式・文字種の決まり |
| 4 | ファイル一覧 | 本書で定義する全ファイルの一覧 |
| 5 | 装置設定ファイル (F01) | JSON形式の入力ファイル |
| 6 | 計測結果ファイル (F02) | CSV形式の出力ファイル |
| 7 | 上位連携ファイル (F03) | 固定長形式の出力ファイル |
| 8 | 計測生データファイル (F04) | バイナリ形式の出力ファイル |
| 9 | 計測APIリクエスト (F05) | HTTP (form-urlencoded) の送信電文 |
| 10 | 収集エージェント設定ファイル (F06) | TOML形式の入力ファイル |
| 11 | ファイル連携タイミング一覧 | 補足シート<br>各ファイルの連携タイミングと注意事項 |
| 12 | コード値一覧 | ファイル中で使う区分値 (コード) の一覧 |

## 3. 共通仕様

| 節 | 説明 |
|---|---|
| 用語定義 | 本書で使う業務用語 (計測装置・上位システム・チャンネル・レコード・サンプルデータ等) とその説明 |
| 表記規約 | 表中の記号の意味<br>`○` = 必須、`-` = 該当なし、`※` = 条件付き必須 (条件は「出現条件」列に記載)、<br>`【要確認】` = 資料から確認できず判断が必要 |
| データ型記法 | テキスト形式で使うデータ型 (文字列・整数・小数・数値・2値・日付・日時・時刻・配列・オブジェクト・バイナリ) の意味 |
| 固定長属性記法 | 固定長ファイルの属性記号の意味<br>`X` = 半角文字、`N` = 全角文字、`9` = 符号なし数字、`S9` = 符号付き整数、<br>`9V9` / `S9V9` = 暗黙小数点付きの数値、`P` / `Z` / `B` = パック10進 / ゾーン10進 / バイナリ<br>埋め文字と寄せ方も示す |
| バイナリ型記法 | バイナリファイルで使う型 (`uint8`〜`uint64`、`int8`〜`int64`、`float32` / `float64`、`char[n]`、`byte[n]`、`bitfield8/16/32`、`bcd[n]`、可変長) のサイズと意味 |
| 日付時刻形式 | 日付・時刻・日時・UNIX 時刻の書式 (例: `YYYYMMDD`、ISO 8601、タイムゾーン) |
| 文字種・禁則文字 | 使ってよい文字種、使ってはいけない文字 (制御文字等)、外字の扱い |

## 5. ファイル別シート (F01〜F06)

1ファイルにつき1シートで、次の節が上から順に並びます。  
フィールド定義の列はファイル形式ごとに異なります。  

### 5.1 共通の節

| 節 | 説明 |
|---|---|
| ファイルの概要 | そのファイルを何のために入力・出力するのか、誰が作り誰が使うのかを文章で説明 |
| ファイル基本情報 | ファイルの属性・運用条件 (下表) |
| レコード構成 | 複数種類のレコードから成るファイル (固定長・バイナリ) で、レコードの種類と並び順を示す |
| フィールド定義 | ファイルに含まれる項目の定義<br>形式別の列で記載 (5.3以降) |
| 補足 | フィールド定義だけでは表せない規則 (CRC 計算範囲、記述規約、凡例等) |
| サンプルデータ | 実際のファイル内容の例 (値は架空)<br>バイナリは、16進ダンプで示す |

### 5.4 フィールド定義: JSON / TOML (F01・F06)

オブジェクト・テーブルごとに表を分けて記載します。  
(例: ルートオブジェクト、`channels`要素、`[agent]`テーブル)  

| 列 | 説明 |
|---|---|
| No. | 表内の連番 |
| JSONパス / キーパス | 項目の位置<br>JSONは`$.channels[*].id`、TOMLは`server.tls.enabled`のように表す |
| 説明 | 項目の意味 |
| データ型 | 共通仕様のデータ型記法 (文字列・整数・配列・オブジェクト等) |
| サイズ | 最大文字数・桁数 (配列・オブジェクトは`-`) |
| 必須 | `○` / `※` / `-` |
| NULL | `null`を許すかどうか (TOMLにはnullが無いため、常に`-`) |
| フォーマット | 値の書式・値範囲 (例: `YYYY-MM-DDTHH:MM:SS+09:00`、`1から128まで`、TOMLの型名) |
| デフォルト値 | 省略時に使われる値 |
| 出現条件 | 条件付き必須 (`※`) の場合に、どんなときに設定するか |
| 備考 | 参照先のコード値・下位の表、補足事項 |

TOMLシートには補足として「TOML記述規約」(コメント・キー・文字列・整数・浮動小数点・日時・配列・重複・null の扱いと準拠仕様) があります。

### 5.7 フィールド定義: バイナリ (F04)

| 列 | 説明 |
|---|---|

| 節 | 説明 |
