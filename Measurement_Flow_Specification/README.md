# 測定フロー設計書 項目説明

対象: `[測定フロー設計書]MeasCore_DMM抵抗測定.xlsx` (見本)  

プログラムが計測器を制御して行う測定処理 (計測器の接続・初期化、測定、合否判定、結果保存) の流れを記載する書類である。  
1冊で1つの測定フローを扱う。  

見本は、架空の「電子部品特性測定システム」の測定制御部`MeasCore`が、SCPI対応のDMM (デジタルマルチメータ、スキャナカード付き) をPyVISA経由で制御し、4端子抵抗を繰返し測定して合否を判定する例である。  
見本の名称・機種・数値は全て架空の記入例である。

## 概要測定フロー

測定処理全体のフロー図と、その説明表で構成する。  
図中の赤丸数字は、説明表の番号と対応する。  
操作者の指示 (測定開始・取付完了) は手操作入力、測定点の繰返しはループ端で表す。  

| 列 | 説明 |
|---|---|
| 番号 | 赤丸の説明番号<br>判断の番号は判定IDを兼ねる |
| 記号 | 図形の種類 (手操作入力・処理・判断・データ・定義済み処理・ループ始端 / 終端など) |
| 項目 (図形ラベル) | 図形に書かれた文言 |
| 処理内容 | その図形で行う処理<br>末尾に遷移先を`(次→2)`や`(Yes→5 ／ No→18)`の形で書く<br>データの受け渡しは`(3へのデータ入力、点線)`の形で書く |
| 経緯・理由・背景 | その処理を行う理由や背景 |

## 詳細フロー (計測器の接続・初期化 / 1点の測定)

概要測定フローの定義済み処理 (二重縦線長方形) を1ページに展開した詳細フロー図と、その説明表で構成する。  
番号は`<展開元の番号>-<連番>`の形式 (例: `5-1`、`9-1`) とする。  

| ページ | 内容 |
|---|---|
| 計測器の接続・初期化 (`5-1`〜`5-14`) | 通信の確立、識別情報の問合せと機種の確認、初期化、自己診断、計測器管理台帳による校正期限の確認、測定設定、エラー記録の読出し |
| 1点の測定 (`9-1`〜`9-13`) | チャネル切替、安定待ち、繰返し測定、タイムアウト時の再試行、無効値・外れ値の除外と統計処理 |

| 列 | 説明 |
|---|---|
| 番号 | 赤丸の説明番号<br>判断の番号は判定IDを兼ねる |
| 記号 | 図形の種類 (準備・ループ始端 / 終端・記憶データを含む) |
| 項目 (図形ラベル) | 図形に書かれた文言 |
| 処理内容 | その図形で行う処理 (送るSCPIコマンドを含む) と遷移先<br>遷移先には「終了」もあり、終了時に概要測定フローへ返す結果 (使用可否・エラー種別・測定結果) を書く |
| 経緯・理由・背景 | その処理を行う理由や背景<br>確認が必要な事項は【要確認】と書く |

## 判定・分岐一覧

フロー図中の全ての判断 (ひし形) を一覧にしたものである。  

| 列 | 説明 |
|---|---|
| 判定ID | フロー図の判断の番号 |
| フロー図 | 判断が載っているページ (P1: 概要測定フロー、P2 / P3: 詳細フロー) |
| 判定内容 | 判断の条件 |
| Yes の場合 | 条件を満たすときの遷移先 (図形ラベルと番号) |
| No の場合 | 条件を満たさないときの遷移先 (図形ラベルと番号) |
| 関連エラー | その判断に関係するエラー種別<br>該当なしは`—` |

## 入出力処理設計

測定処理を初期処理・メイン処理・例外発生時処理・終了処理の順に分け、処理ごとの内容と入出力データを記載する。  

| 列 | 説明 |
|---|---|
| 処理No. | 大分類 (1: 初期処理、2: メイン処理、3: 例外発生時処理、4: 終了処理) と、その中の連番 |
| 開始条件 | 測定処理が開始される契機 |
| 処理内容 | 処理の見出し (対応するフロー図の番号) と具体的な手順・SCPIコマンド・条件・エラー時の扱い |
| IN / OUT | 入力か出力かの区別<br>該当なしは`-` |
| データ | 入出力されるデータ |
| 対応する内部処理 | 測定概要の「処理のまとまり」との対応 |

## 表記

| 表記 | 意味 |
|---|---|
| 【要確認】 | 資料から確認できず、人間の判断が必要な事項 (機種名・既定値・顧客との合意など) |
| `—` | 該当なし |
| 赤丸数字 | フロー図の図形と説明表の番号を対応付ける説明番号 |
| 赤枠・赤字 | フロー図のエラー経路 (異常時の処理) |
