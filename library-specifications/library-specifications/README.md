# ライブラリ設計書 見本の項目説明

本ディレクトリのライブラリ設計書見本 (MochDatの例) について、各シートの記載項目を簡単に説明する。  

## 対象ファイル

| ファイル | 対象 | ライブラリ形式 |
|---|---|---|
| `[ライブラリ設計書]MochDat_Linux(.so).xlsx` | Linux | 共有ライブラリ |
| `[ライブラリ設計書]MochDat_Windows(.dll).xlsx` | Windows | ダイナミックリンクライブラリ |
| `[ライブラリ設計書]MochDat_Linux(.a).xlsx` | Linux | 静的ライブラリ |
| `[ライブラリ設計書]MochDat_Windows(.lib).xlsx` | Windows | 静的ライブラリ |

シート0〜9は4ファイルで共通の構成であり、OS固有の記述だけが異なる。  
シート10以降は動的ライブラリ (.so/.dll) と静的ライブラリ (.a/.lib) で構成が異なる。  

| シート | .so / .dll | .a / .lib |
|---|---|---|
| 0〜7 | 共通 | 共通 |
| 8-1〜9-3 | API詳細 (1APIにつき3シート) | API詳細 (1APIにつき3シート) |
| 10 | バイナリ仕様 | 静的ライブラリ仕様 |
| 11 | エクスポートシンボル一覧 | 公開シンボル一覧 |
| 12 | 互換性・バージョン方針 | リンク・組込み規約 |
| 13 | ビルド・配布・SBOM | 互換性・バージョン方針 |
| 14 | — | ビルド・配布・SBOM |

## 全シート共通のヘッダ

| 項目 | 説明 |
|---|---|
| システム名 | ライブラリを利用するシステムの名称 |
| ライブラリ名 | ライブラリ名と実ファイル名 (SONAMEやDLL名) |
| 作成者 / 作成日 | 初版の作成者と作成日 |
| 更新者 / 更新日 | 最終更新者と最終更新日 |
| シート見出し | シートの題名<br>シート全体がOS固有の場合はその旨を付記する |

## 0.表紙

| 項目 | 説明 |
|---|---|
| 表題 / 副題 | 文書名と、対象OS・ライブラリ形式 |
| ドキュメント名 | 本書の正式名称 |
| 文書版数 | 本書の版。ライブラリの版とは別に管理する |
| システム名 / ライブラリ名 | 対象システムと対象ライブラリ |
| 対象バイナリ | 本書が記述する実ファイル |
| 対象ライブラリ版 | 本書が対象とするライブラリの版 |
| 対象プラットフォーム | 対象OS・アーキテクチャ |
| 公開形態 | 公開言語やリンク方式などの提供形態 |
| 正本の扱い | 他文書と記載が食い違う場合にどれを正とするか |
| 本書の位置付け | 本書の目的と読者 |
| 関連文書 | 他OS版・他形式版の設計書など |
| 凡例 | 黄色背景 (OS固有の行・セル) 、橙色のシート見出し (シート全体がOS固有) 、<br>◆ (本文中のOS固有記述) 、スレッド安全性区分、引数の方向、`-` (該当なし) などの表記の意味 |

## 0-1.改版履歴

| 項目 | 説明 |
|---|---|
| 版 | 文書の版数 |
| 改版日 | 改版した日付 |
| ライブラリ版 | その改版が対応するライブラリの版<br>文書だけの改版では変えない |
| 区分 | 新規・追加・変更・削除の別 |
| 改版箇所 (シート) | 変更したシート |
| 改版内容 | 変更の要旨 |
| 変更者 | 改版した人 |

## 0-2.シート構成

| 項目 | 説明 |
|---|---|
| シート一覧 | 各シートの名称 (シートへのリンク付き) 、記載内容、OS差分 (一部 / 全体) |
| シート間の関係図 | 文書管理 → 全体像 → 共通規約 → 定義 (一覧) → API詳細 → バイナリ・配布の階層関係 |
| 主な相互参照 | シート間で値を一致させる項目 (API ID、導入版、エラーコードなど) |

API詳細シートは、APIを追加するごとにN-1〜N-3の3シートを1組として追加する。<br>

## 1.機能概要

| 項目 | 説明 |
|---|---|
| ライブラリの目的 | ライブラリが解決する課題と提供する機能の要約 |
| 利用者 (上位モジュール) | ライブラリを呼び出すモジュール<br>実装技術・リンク方式・備考を記載する |
| 対象範囲 (機能一覧) | 機能名・大分類・中分類・概要・対応APIの一覧 |
| 対象外 (スコープ外) | ライブラリが扱わない機能 |
| 前提・制約 | 動作の前提条件と制約事項 |

## 2.構成・依存関係

| 項目 | 説明 |
|---|---|
| レイヤ構成図 | 利用側・公開API・内部モジュール・OSの階層構成 |
| 構成要素 | 構成要素名、種別、ファイル、公開区分 (公開 / 内部) 、説明 |
| 実行時依存関係 | 依存先、種別、要求バージョン、提供元、備考<br>静的版では「利用側の最終リンクで解決される依存関係」となる |
| データの受け渡し | データ、方向、形式、文字コード、受け渡し方法、所有権・寿命 |

## 3.呼出シーケンス・状態遷移

| 項目 | 説明 |
|---|---|
| 標準の呼出し順序 | 利用側の処理、呼び出すAPI、ハンドル状態 (前→後)、備考を手順順に記載する |
| ハンドル状態の定義 | ハンドルが取り得る状態とその意味 |
| 状態遷移表 | API × 状態ごとの可否と遷移先 |
| サンプルコード (C) | 標準的な呼出し例 |
| OS別サンプルコード | .soはC++ラッパとdlopen<br>.dllはC#のP/InvokeとLoadLibraryExW<br>静的版はC++ラッパとビルド例 |

## 4.API共通規約

| 項目 | 説明 |
|---|---|
| 共通規約 | 全公開APIに適用する規約を分類・規約・理由・補足で記載する。<br>分類は命名、公開言語、戻り値、出力引数、NULL許容、文字列 (入力 / 出力・コピー / 出力・参照) 、<br>メモリ所有権、構造体の版管理、列挙値、整数型、真偽値、<br>スレッド安全性、コールバック、例外、エラー詳細、ログ・プロセス制御、初期化・終了、将来の拡張、<br>OS固有事項 (Linuxのforkやシグナルなど) |
| 公開マクロ | エクスポート指定・呼出規約・非推奨指定などのマクロ定義と`extern "C"`の宣言例 |

## 5.公開API一覧

| 項目 | 説明 |
|---|---|
| 公開関数 | API ID、種別、機能分類、API名、宣言ヘッダ、スレッド安全性、<br>導入版、状態 (有効 / 非推奨など) 、概要、詳細シート |
| コールバック | 利用側が実装する関数のID、型名、機能分類、呼出しスレッド、導入版、概要 |
| 宣言一覧 | 公開ヘッダから抜粋した関数宣言 |

API ID・導入版・状態は本シートが正本であり、他シートはこれに合わせる。  

## 6.型定義

| 項目 | 説明 |
|---|---|
| 宣言 | 公開ヘッダから抜粋した型の宣言 |
| 型情報 (列挙型・不透明型) | 型の用途、値の範囲、扱い方 |
| 型情報 (構造体) | メンバ名、型、オフセット、サイズ、方向、導入版、説明 |
| 型情報 (コールバック型) | 型名、引数、戻り値、導入版、備考 |
| 定数 | 定数名、値、型、用途、導入版 |

## 7.エラーコード定義

| 項目 | 説明 |
|---|---|
| エラーコード一覧 | 定数名、値、区分、意味、主な発生条件、呼出側の対処、再試行の可否、導入版、メッセージ文字列 |
| OSエラーとの対応 | OSのエラー (Linuxはerrno、WindowsはGetLastError) 、発生箇所、変換後のエラーコード、備考 |

## N-1.IF定義 (API詳細)

見本では、`8-1.IF定義(open_file)`と`9-1.IF定義(get_res)`が該当する。  

| 項目 | 説明 |
|---|---|
| API基本情報 | API ID、API名、機能分類、導入版、宣言ヘッダ、状態、スレッド安全性、置き換え対象、概要、関連API |
| 宣言 | 関数のプロトタイプ宣言 |
| 引数 | 引数名、型、方向、NULL許容、値の範囲・形式、所有権・寿命、説明 |
| 戻り値 | 戻り値、条件、そのときの出力引数の状態 |
| 事前条件・事後条件・副作用 | 呼出し前に満たすべき条件、呼出し後に保証される状態、副作用や互換性の注意 |

## N-2.処理記述 (API詳細)

見本では、`8-2.処理記述(open_file)`と`9-2.処理記述(get_res)`が該当する。  

| 項目 | 説明 |
|---|---|
| 処理概要 | APIが行う処理の要約 |
| 処理手順 | 【1】【2】… の大手順と、①②… や［a］［b］… の小手順で処理を順に記載する |
| エラー処理 | 失敗時の資源解放、例外の扱い、通知方法 |
| 排他制御 | 共有状態の保護方法と同時呼出しの可否 |
| 性能目標 (参考値) | 処理時間などの目標値と測定条件 |

## N-3.入出力パターン (API詳細)

見本では、`8-3.入出力パターン(open_file)`と`9-3.入出力パターン(get_res)`が該当する。  

| 項目 | 説明 |
|---|---|
| 区分 | 正常、境界、異常、OS固有、互換、データ、並行、再入、寿命などの観点 |
| 入力条件 | 引数や事前状態の条件 |
| 期待する戻り値 | その条件で返るべき値 |
| 期待する出力・状態 | 出力引数やハンドル状態の期待値 |
| 備考 | 補足事項 |

単体テストの観点として利用する。
