# 秘密保持契約書 (外注先用) README

`秘密保持契約書_外注先用.docx`の各セクション・各項目の役割を簡単に説明する。  

- 用途: 自社 (甲=委託者) と外注先 (乙=受託者) がソフトウェア開発業務の検討・遂行に先立ち締結するNDAのひな形  
- 形式: 双務型 (甲乙双方が開示者にも受領者にもなる)  
- 記入箇所: `【　】`で囲まれた部分を案件に合わせて記入する

## 表題・前文

- 表題: 「秘密保持契約書」  
- 前文: 甲・乙の名称を記入し、「本業務」 (甲が乙に委託または委託を検討するソフトウェア開発等の業務) と「本契約」を定義する  

## 本文

### 第1条 (目的)

本業務の検討・協議・見積り・遂行を「本目的」と定義し、本契約がその目的で相互に開示する秘密情報の取扱いを定めることを示す。  
本業務の概要は別紙1で定める。  

### 第2条 (定義)

- 第1項: 「秘密情報」「開示者」「受領者」を定義する。  
  秘密情報は次のいずれかに該当する情報で、複製物や派生資料を含む  
  - 第1号: 有形媒体で開示され、秘密である旨が明示された情報  
  - 第2号: 口頭・画面共有等で開示され、開示時に告知し、開示後14日以内に書面で特定・通知された情報  
  - 第3号: 共有基盤 (リポジトリ、開発環境、チャットツール等) に格納された情報のうち、別紙1で指定した範囲  
  - 第4号: 明示の有無を問わず秘密情報となる情報。  
          ソースコード・未公開設計書 (ア)、システム・ネットワーク構成 (イ)、認証情報 (ウ)、  
          脆弱性等の未公開情報 (エ)、テストデータ・本番データ (オ)、個人情報 (カ)  
- 第2項: 「書面」に電子メール・電子契約等の電磁的記録を含めることを定める  

### 第3条 (秘密情報の例外)

受領者が客観的資料で証明できる次の情報を秘密情報から除外する。  
ただし、認証情報には適用せず、個人情報は第9条・関係法令の義務を免れない。  

- 第1号: 開示時点で公知の情報
- 第2号: 開示後、受領者の責めによらず公知となった情報
- 第3号: 開示時点で受領者が正当に保有していた情報
- 第4号: 正当な第三者から秘密保持義務なく取得した情報
- 第5号: 秘密情報によらず独自に開発・取得した情報

### 第4条 (秘密保持義務)

- 第1項: 善管注意義務による秘密保持と、無断の第三者開示・漏えいの禁止
- 第2項: 承諾なしに開示できる者。役員等 (派遣労働者を含む) 、守秘義務を負う専門家、第6条で承諾を得た第三者
- 第3項: 役員等に在職中・退職後の同等義務を課し、その違反に責任を負う
- 第4項: 法令・裁判所命令等による開示の例外と、開示者への通知・協力
- 第5項: 本契約の内容・協議内容自体の秘密保持
- 第6項: 法令に基づく通報や権利の行使・防御に必要な場合の開示・使用の例外

### 第5条 (目的外使用の禁止等)

- 第1項: 本目的以外での使用禁止
- 第2項: 必要範囲を超える複製の禁止
- 第3項: リバースエンジニアリング・逆コンパイル・逆アセンブルの禁止。本目的に必要なソースコード閲覧・静的解析・動作確認等は除く
- 第4項: ソースコードの開示義務を伴うライセンス条件 (いわゆるコピーレフト) が適用される態様でのOSSとの結合・利用・頒布の禁止

### 第6条 (第三者への開示)

- 第1項: 再委託先等への開示は開示者の事前書面承諾が必要。名称・所在地 (国外の場合は国名) ・範囲・目的を通知する
- 第2項: 開示者は承諾を不合理に拒否・遅延しない
- 第3項: 再委託先等に同等以上の義務を書面で課し、その違反に責任を負う
- 第4項: 求めに応じて再委託先等の管理状況を報告する

### 第7条 (秘密情報の管理)

- 第1項: 受領者が講じる最低限の管理措置
  - 第1号: アクセス権限の最小化と付与・変更・削除の記録
  - 第2号: 認証情報の安全な保管、平文送信・保存や共有の禁止、終了時の使用停止・無効化への協力
  - 第3号: 保存・送信時の暗号化等の保護措置
  - 第4号: 未承認の私物端末・個人アカウント・外部サービスへの保存・入力の禁止
  - 第5号: マルウェア対策・脆弱性対応等の不正アクセス防止措置
- 第2項: 開示者は事前通知の上、措置の実施状況の書面報告を求めることができる

### 第8条 (生成AI等の外部AIサービスの利用)

- 第1項: 開示者の事前書面承諾がない限り、外部AIサービスへの秘密情報の入力・アップロード・処理を禁止する
- 第2項: 承諾がある場合も、次のすべてを満たすサービスに限る
  - 第1号: 入出力が学習・改善に利用されない設定・契約条件であること
  - 第2号: 提供者が秘密保持義務を負い、利用目的・保存期間・削除方法が明確であること
  - 第3号: 業務用契約で利用者・アクセス権限を管理できること
- 第3項: 別紙1に記載した範囲で、第8条第1項・第6条第1項の承諾と第7条第1項第4号の利用承認があったものとみなす
- 第4項: AIモデルの学習・ファインチューニング・RAG用データベース構築等への利用禁止
- 第5項: 秘密情報を含むAI出力は秘密情報として扱う

### 第9条 (個人情報の取扱い)

- 第1項: 個人情報開示前の範囲・取扱方法・安全管理措置の協議と必要最小限化
- 第2項: 個人情報保護法・ガイドラインの遵守と目的外取扱いの禁止
- 第3項: 個人データの取扱委託時の「委託元」「委託先」の定義、監督への協力、無断再委託の禁止
- 第4項: 取扱開始前に別紙1・個別契約・覚書で取扱条件を書面合意する。法改正時は施行日までに見直す
- 第5項: 漏えい等発生時の通知と、法令上の報告・本人通知への協力
- 第6項: 外国にある第三者への提供時の個人情報保護法第28条等に基づく措置の事前確認

### 第10条 (漏えい等発生時の対応)

- 第1項: 「漏えい等」 (おそれを含む) を定義し、発覚時の開示者への即時通知を定める
- 第2項: 原因調査・被害拡大防止措置と、経過・結果・再発防止策の書面報告
- 第3項: 受領者の責めによる場合は対応費用を受領者が負担する
- 第4項: 行政機関への報告・本人通知・公表が必要な場合の相互協力

### 第11条 (返還及び廃棄)

- 第1項: 契約終了・目的終了・請求時の返還または復元不能な廃棄・消去と、共有基盤アカウント・認証情報の利用停止
- 第2項: 請求時に別紙2の様式で実施状況を証する書面を提出する。保持する情報がある場合はその範囲・理由・管理方法・期限を記載する
- 第3項: 返還・廃棄の例外
  - 第1号: 法令で保存が義務付けられているもの
  - 第2号: 自動バックアップに保存され、直ちに消去が困難なもの
- 第4項: 例外で保持する情報の保護義務の継続と、保存期間満了後の消去、復元時の再消去

### 第12条 (権利の非許諾等)

- 第1項: 秘密情報の開示により知的財産権・ノウハウを譲渡・許諾しないことを確認する
- 第2項: 開示者は開示権限のみ保証し、正確性・完全性・非侵害等は保証しない
- 第3項: 相手方の秘密情報に基づく発明等をした場合の通知と、貢献度を踏まえた権利帰属の協議

### 第13条 (公正な取引)

- 第1項: 本契約は情報開示義務や本業務の契約締結義務を課さない
- 第2項: 甲は乙のノウハウ・ソースコード等の開示を必要範囲を超えて求めない。求める場合は範囲・目的を明示して同意を得る
- 第3項: 本契約は個別契約の成果物・知的財産権の帰属や対価を定めない。知的財産権等の譲渡・許諾は別途書面で定める
- 第4項: 独占禁止法・取適法・フリーランス法等の遵守

### 第14条 (輸出管理)

- 第1項: 規制技術を含む場合、国外提供・持出し・国外サーバでの取扱いに先立つ該非判定・取引審査と許可等の手続
- 第2項: 開示者は規制対象技術を含む場合に事前通知する
- 第3項: 国外の再委託先等への開示や国外サーバでの取扱いは事前通知と書面承諾が必要

### 第15条 (損害賠償及び差止め)

- 第1項: 帰責事由ある違反時の賠償範囲 (民法第416条の範囲と合理的な弁護士費用)
- 第2項: 違反または違反のおそれがある場合の差止め・予防措置の請求

### 第16条 (反社会的勢力の排除)

- 第1項: 当事者・役員が反社会的勢力に該当しないこと、および次の関係を有しないことの表明保証
  - 第1号: 反社会的勢力による経営支配・実質的関与
  - 第2号: 不正な利益等を目的とした反社会的勢力の利用
  - 第3号: 資金提供・便宜供与等の関与
  - 第4号: 役員等の社会的に非難されるべき関係
- 第2項: 次の行為を行わない旨の確約
  - 第1号: 暴力的な要求行為
  - 第2号: 法的責任を超えた不当な要求行為
  - 第3号: 脅迫的言動・暴力の使用
  - 第4号: 風説の流布・偽計・威力による信用毀損・業務妨害
  - 第5号: 前各号に準ずる行為
- 第3項: 違反時の無催告解除
- 第4項: 解除した側は賠償責任を負わず、解除された側は第15条第1項の範囲で賠償する

### 第17条 (有効期間)

- 第1項: 有効期間は締結日から1年間。満了1か月前までに別段の意思表示がなければ1年ごとに自動更新する
- 第2項: 締結日前に開示された秘密情報にも適用する
- 第3項: 終了後の存続条項。第4条〜第11条・第14条は3年間、第12条・第13条・第15条・第16条第4項・第18条〜第21条は無期限で存続する
- 第4項: 3年経過後も延長される情報
  - 第1号: 不正競争防止法上の営業秘密は、営業秘密に該当する間
  - 第2号: 個人情報・認証情報は、返還・廃棄・消去の完了まで
  - 第3号: 第11条第3項で保持する情報は、保持の終了まで

### 第18条 (権利義務の譲渡禁止)

契約上の地位・権利義務の無断譲渡や担保提供を禁止する。  

### 第19条 (他の契約との関係)

個別契約で本契約の特定規定の変更・不適用を書面で明示的に合意した場合に限り、その範囲で個別契約を優先する。  

### 第20条 (準拠法及び合意管轄)

- 第1項: 準拠法を日本法とする
- 第2項: 第一審の専属的合意管轄裁判所を定める。裁判所名は`【　】`に記入する

### 第21条 (協議)

定めのない事項や解釈の疑義は、信義誠実の原則に従い協議して解決する。  

## 後文・署名欄

- 後文: 書面で締結する場合は2通作成して各1通を保有し、電子契約の場合は電磁的記録に電子署名して各自保管する
- 締結日: 年月日を`【　】`に記入する
- 署名欄: 甲・乙それぞれの所在地・名称・代表者を記入し押印する

## 別紙2 返還・廃棄 (消去) 証明書の様式

第11条第2項に基づき受領者が開示者へ提出する証明書の様式。  

- 日付・宛先: 提出日と開示者の名称 (御中)
- 提出者欄: 受領者の所在地・名称・責任者と押印
- 本文: 締結日付の秘密保持契約書第11条に基づき返還・廃棄・消去を実施したことを証明する。  
  第11条第3項で保持する情報は対象外とする  

| 項目 | 説明 |
|---|---|
| 対象となる秘密情報 | 返還・廃棄・消去の対象 |
| 保管媒体・保存場所 | ファイルサーバ・開発端末・クラウドストレージ等 |
| 実施方法 | 返還・物理的破壊・復元できない方法による消去・その他 |
| 実施日 | 実施した年月日 |
| 実施責任者 | 部署・氏名 |
| 共有基盤のアカウント・認証情報の停止状況 | 停止済みまたは該当なし |
| 第11条第3項により保持する情報 | 保持する情報の範囲・保存理由・管理方法・保存期限または消去予定時期。<br>該当しない場合は「該当なし」 |
