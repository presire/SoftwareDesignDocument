# 見本: `[サンプル]掲示板閲覧・投稿.xlsx`のフォーマット

機能概要書の全シート構成を示す見本について、シートごとの項目の意味をまとめる。  

- 見本は読み取り専用  
  上書き・複製・内容 (システム名・画面名・テーブル名等) の流用をしない。  

## 1. ブック構成

1冊 = 1大分類機能  
シートは次の順に並ぶ。(見本は画面 6 件 → 全 21 シート)  

| 順 | シート名 | 説明 | 用紙 |
|---|---|---|---|
| 1 | `1.機能概要` | システム全体の機能階層と、本冊が対象とする機能の範囲・各機能の説明 | A3 横 |
| 2 | `2.画面遷移` | 対象画面の一覧と、画面間の遷移関係 (表 + 画面遷移図) | A4 縦 |
| 3 | `3.データフロー` | 画面・処理・テーブル・ファイル・外部システム間のデータの流れ (表 + データフロー図) | A4 縦 |
| 4〜 | `N-1.レイアウト(画面名)` | 画面の見た目 (スクリーンショット) | A4 縦 |
|  | `N-2.処理記述(画面名)` | 画面の業務目的・操作手順・入力制御・ボタンごとの処理 | A4 縦 |
|  | `N-3.項目一覧(画面名)` | 画面上の全 UI 項目の属性一覧 | A4 縦 |

- `N`は画面ごとに4から連番。  
  画面ごとにN-1〜N-3の3シートを持つ。  
- タブを持つ画面はレイアウトをタブごとに分割する。  

## 2. 全シート共通

### 2.1 文書ヘッダ

全シートの先頭に置く文書情報。  

| 項目 | 説明 |
|---|---|
| システム名 | 対象システムの名称 |
| 機能名 | 本冊の大分類機能名 (= ファイル名の `<機能名>`) |
| 作成者 | 初版の作成者 |
| 作成日 | 初版の作成日 (`YYYY/MM/DD`) |
| 更新者 | 最終更新者 (初版は空欄) |
| 更新日 | 最終更新日 (`YYYY/MM/DD`) |

### 2.2 タイトル

文書ヘッダの下に置くシートの見出し。  

| シート | タイトル |
|---|---|
| 1.機能概要 | `機能概要` |
| 2.画面遷移 | `画面遷移` |
| 3.データフロー | `データフロー` |
| N-1.レイアウト | `【レイアウト（〇〇画面）】` |
| N-2.処理記述 | `処理記述 (〇〇画面)` |
| N-3.項目一覧 | 見本は `処理記述 (〇〇画面)` だが**見本の誤り**。正しくは `項目一覧 (〇〇画面)` |

### 2.3 書式

- `■ 〇〇一覧`の見出し帯は青、表ヘッダは薄い青で塗る。  
- 該当なしのセルは`-`  

## 3. `1.機能概要`

上部に**機能概要図** (システムの全大分類 > 中分類 > 機能 を並べ、本冊の対象範囲を赤枠で示した図)、その下に本文を置く。  

| 見出し / 記号 | 説明 |
|---|---|
| `≪業務範囲≫` | 本冊が対象とする業務の範囲  対象と対象外を1〜数行で書く |
| `≪対象機能一覧≫` | 本冊の対象機能を中分類ごとに列挙する |
| `＜A1: 中分類名＞` | 中分類<br>`A1`は機能ID (大分類ID + 連番) |
| `①` + 機能名 | 対象機能<br>丸数字は冊内の通番で、機能概要図の番号バッジと一致する |
| `・` + 要約 | 機能の1〜2行の要約 |
| `≪全体≫` | 対象機能ごとの詳細説明 |
| `①` + 機能名 | 説明する機能<br>(≪対象機能一覧≫ と同じ番号・名称) |
| `・` + 説明 | 機能の詳細<br>目的・入力・処理・出力・関連画面/テーブル・処理パターンを 5〜10 行で書く |

## 4. `2.画面遷移`

上から表を並べ、最後に**画面遷移図** (対象画面・対象外画面を箱、遷移を矢印 + トリガーで表した図) を置く。  

### ■ 対象画面一覧

本冊で画面別シート (N-1〜N-3) を作る画面  
並び順・名称は画面別シートと一致させる。  

| 列 | 説明 |
|---|---|
| No. | 通番 (= 画面別シートの並び順) |
| 画面名 | 画面の正式名称 (`〇〇画面`) |
| URLパス | 画面を開く URL・ルート。Web 以外はウィンドウ/クラス名等 |
| 遷移元 | この画面へ遷移してくる画面 (起点画面は `(トップ)` 等) |
| 遷移先 | この画面から遷移できる画面 (`, ` 区切り) |
| 備考 | 補足 (内包するフォーム・モーダル等)。無ければ `-` |

### ■ 対象外画面一覧

同じシステム内にあるが本冊の対象外とする画面 (他冊で扱う画面)。図ではグレーで示す。  

| 列 | 説明 |
|---|---|
| No. | 通番 |
| 画面名 | 画面の名称 |
| URLパス | 画面の URL・ルート |
| 備考 | 画面の用途・対象外とする理由 |

### ■ 遷移一覧

画面間の遷移を 1 遷移 1 行で列挙する。  
画面遷移図の矢印と1対1に対応する。  

| 列 | 説明 |
|---|---|
| No. | 通番 |
| 遷移元 | 遷移前の画面 (対象/対象外画面一覧の名称) |
| 遷移先 | 遷移後の画面 (同上) |
| トリガー | 遷移のきっかけとなる操作 (ボタン押下・リンククリック等) |
| 条件 | 遷移が起きる条件 (権限・入力状態等)。無条件は `-` |

> 契約では帳票がある場合に `■ 帳票一覧` (No. / 帳票名 / 出力元画面 / 形式 / 備考) も置く。(見本は帳票なし)  

## 5. `3.データフロー`

上から表を並べ、最後に**データフロー図** (画面・処理・テーブル・外部ファイル・外部システムを箱、データの流れを 参照/更新/起動 の矢印で表した図) を置く。  

### ■ 画面一覧

| 列 | 説明 |
|---|---|
| No. | 通番 |
| 画面名 | 対象画面の名称 (画面遷移の対象画面一覧と一致) |
| 説明 | 画面がデータについて何をするかの要約 |
| 参照テーブル | 画面が読み取るテーブル (`, ` 区切り。無ければ `-`) |
| 更新テーブル | 画面が登録・更新・削除するテーブル (同上) |

### ■ 処理一覧

画面から呼ばれるサーバ処理・バッチ・サービス等。  

| 列 | 説明 |
|---|---|
| No. | 通番 |
| 処理名 | 処理の名称 (クラス名・サービス名等) |
| 説明 | 処理内容の要約 |
| 起動元 | 処理を呼び出す画面または処理 |
| 入力 | 処理が受け取るデータ |
| 出力 | 処理の結果 (更新先・返却データ・判定結果等) |

### ■ テーブル一覧

| 列 | 説明 |
|---|---|
| No. | 通番 |
| テーブル名 | DB テーブルの物理名 |
| 説明 | テーブルが保持するデータの内容 |
| 他処理参照 | 本冊以外の処理でも参照されるか (`あり` / `なし`) |
| 他処理更新 | 本冊以外の処理でも更新されるか (`あり` / `なし`)。図ではテーブル名に `※` を付けて示す |

### ■ 外部ファイル一覧

DB以外に読み書きするファイル。  

| 列 | 説明 |
|---|---|
| No. | 通番 |
| ファイル名 | ファイルのパス・名称パターン |
| 形式 | ファイル形式 (JSON / CSV 等) |
| 入出力 | 本冊の処理から見た向き (`入力` / `出力` / `入出力`) |
| 関連画面・処理 | ファイルを扱う画面・処理 |
| 説明 | ファイルの内容 |

### ■ 外部システム一覧

| 列 | 説明 |
|---|---|
| No. | 通番 |
| システム名 | 連携する外部システム・サービスの名称 |
| 連携方式 | 通信手段 (HTTPS API / DNS / ファイル連携等) |
| データの流れ | 本システムから見た向き (`参照` / `更新` 等) |
| 説明 | 連携の目的・内容 |

### ■ データフロー一覧

データの流れを1フロー1行で列挙する。  
データフロー図の矢印と1対1に対応する。  

| 列 | 説明 |
|---|---|
| No. | 通番 |
| 起点 | データを扱う主体 (画面・処理) |
| 終点 | 扱われる対象 (テーブル・ファイル・外部システム・起動される処理) |
| フロータイプ | `参照` / `更新` / `参照/更新` / `起動` のいずれか |
| データ内容 | 流れるデータの内容 |

## 6. 画面別シート

### 6.1 `N-1.レイアウト(画面名)`

画面のスクリーンショットを1枚貼るだけのシート (本文テキストなし)  
画像は、`Functional_Overview/screenshots/<機能名>/<画面ID>.png`  

### 6.2 `N-2.処理記述(画面名)`

罫線なしの字下げ文書  
`■画面名` の下に次の 6 節をこの順で置く。  

| 節 | 説明 |
|---|---|
| `□対象業務` | 画面の業務上の目的・概要<br>処理パターンがあれば `＜パターン＞` で列挙 |
| `□処理単位` | 1 回の処理で扱う単位 (画面単位・掲示板単位・明細単位 等) |
| `□基本操作手順` | 利用者の操作パターンごとの手順 (`・パターン名` + `①②…`)<br>操作の結果も書く |
| `□起動時処理` | 画面を開いたときに自動で行う処理 (データ取得・初期値設定等)<br>無ければ`・該当なし` |
| `□入力制御` | 入力項目ごとの制御 (`項目名：` + 必須/形式/桁/連動等) |
| `□ボタンアクション` | ボタンごとの処理 (`【n】〇〇ボタン押下処理` + `・処理内容`)<br>処理・遷移先・エラー時動作・確認ダイアログを書く |

記号の意味:

| 記号 | 意味 |
|---|---|
| `■` | 画面名 |
| `□` | 大セクション (上記 6 節) |
| `・` | 箇条・操作パターン名 |
| `①②…` | 手順番号 |
| `＜＞` | サブカテゴリ (`＜パターン＞` 等) |
| `≪≫` | ボタンのグループ (`≪共通≫`・`≪モーダル名≫`・`≪タブ名≫`) |
| `【n】` | タブ番号 / ボタン番号 (ボタン番号は画面全体で連番) |
| `［］` | 分岐する操作名 (見本では未使用) |

### 6.3 `N-3.項目一覧(画面名)`

画面上のUI項目 (見出し・ラベル・入力欄・ボタン・リンク等) を1項目1行で列挙する表  
ヘッダは2段で、「イベント」の下に4つの状態列が並ぶ。  

| 列 | 説明 |
|---|---|
| No. | 通番 (1〜) |
| 表示ラベル (日) | 画面に表示される文言 (表示文言の無い項目は役割を表す名称) |
| 表示ラベル (英) | ソース上の識別子 (コンポーネント名・変数名・ID 等) |
| データ型 | 項目の種類 (ラベル / テキスト / ボタン / リンク / 選択 等) |
| 表示桁数 | 表示する最大桁数 |
| 入力桁数 | 入力できる最大桁数 |
| 表示位置 | 文字の揃え (左寄せ / 中央 / 右寄せ) |
| 改行有無 | 値の折り返し・複数行表示の有無 |
| 必須 | 入力必須かどうか |
| フォーマット | 表示・入力の書式 (日付・数値形式等) |
| デフォルト値 | 初期表示時の値 |
| イベント / 初期表示 | 画面表示直後の状態 (表示 / 非表示 / 活性 / 非活性) |
| イベント / 操作時 | 操作中・操作後の状態 |
| イベント / データなし時 | 表示データが 0 件のときの状態 |
| イベント / エラー時 | エラー発生時の状態 |
| 選択リスト | 選択肢を持つ項目の選択肢 |
| ツールチップ | マウスオーバー時の説明文 |
| サイズ | 文字サイズ |
| 太さ | 文字の太さ (bold 等) |
| 文字色 | 文字色 |
| 背景色 | 背景色 |
| 補足 | 上記以外の補足 (UI コントロール種別・挙動・根拠 `path:line` 等) |

全列必須  
該当しない列は`-`とし、空欄にしない。

## 8. 見本と契約の差異 (見本を真似しない点)

| 項目 | 見本 | 契約 (生成物) |
|---|---|---|
| 列幅・行高 | 不揃い | 全列 0.5cm・全行 0.7cm の方眼 (`build_xlsx.py` が自動設定) |
| 縦方向の印刷 (1.機能概要 以外) | 1 ページに縮小 | 縮小しない |
| ウィンドウ枠固定 | 一部シートのみ | 全シートでタイトル行の下に固定 |
| 項目一覧のタイトル | `処理記述 (…)` | `項目一覧 (…)` |
