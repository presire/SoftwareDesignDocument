# データベース設計書 記載項目の説明

本フォルダの記載例 (図書貸出管理システム / PostgreSQL 16) を構成する4つの設計書について、シートと項目の意味を簡単に説明する。  

| ファイル | 内容 |
|---|---|
| `[スキーマ定義書]記載例_図書貸出管理システム.xlsx` | DB全体の前提 (共通仕様・データベース / スキーマ / 権限等) |
| `[テーブル定義書]記載例_図書貸出管理システム.xlsx` | ER図・テーブル一覧・テーブル (ビュー) ごとの定義・コード値 |
| `[ストアド定義書]記載例_図書貸出管理システム.xlsx` | ストアドプロシージャ・ファンクションの定義 |
| `[トリガー設定書]記載例_図書貸出管理システム.xlsx` | トリガーの定義 |

各セルで使う表記は以下の通り。  

| 表記 | 意味 |
|---|---|
| `◯`・`○` | NOT NULL・該当あり (Not Null欄・CRUD欄等) |
| `-` | 該当なし・NULL可 |
| `【要確認】` | 資料から確認できず、人間の判断が必要な事項 |

## 1. 全分冊共通のシート

### 1.1 表紙

| 項目 | 説明 |
|---|---|
| `Ver.`・組織名 (左上) | 版数と、文書を発行する組織名 |
| 文書名・システム名・サブタイトル | 文書の種類 (スキーマ定義書等) と対象システム名、システムの概要と対象RDBMS |
| プロジェクト名 / システム名 / ドキュメント名 | 文書情報。どのプロジェクト・システムのどの文書かを示す |
| 版数 / 作成日 / 作成者 | 現行の版と初版の作成日・作成者 |
| 最終更新日 / RDBMS / 組織名 | 最後に改訂した日、対象RDBMSと版、作成組織 |

### 1.2 改訂履歴

| 項目 | 説明 |
|---|---|
| ヘッダ (プロジェクト名 / ドキュメント名 / 作成日 / 作成者) | 全シート共通の見出し行<br>どの文書のシートかを示す |
| 版 | 改訂後の版数 |
| 改訂日 / 改訂者 / 承認者 | 改訂した日と担当者、承認した人 |
| 対象シート | 改訂したシート (全体なら「全シート」) |
| 改訂内容 | 何を追加・変更・削除したか |

### 1.3 シート共通のヘッダ

一覧系シートは「プロジェクト名 / ドキュメント名 / 作成日 / 作成者」、  
テーブル別・ストアド別・トリガー別シートは「プロジェクト名 / スキーマ名 / 論理名 / 物理名 / 作成日 / 作成者」を先頭に置き、そのシートの対象を示す。

## 2. スキーマ定義書

### 2.1 共通仕様

テーブル定義書にも同じシートを収録する。設計書全体で守る前提・規約をまとめる。  

| 項目 | 説明 |
|---|---|
| 本書の目的 | 本書が定義する範囲と対象RDBMS |
| 用語定義 | 業務用語とそれが指すデータ (どのテーブルの1行か) の対応 |
| 表記規約 | 設計書内で使う記号 (`◯`・`-`・`【要確認】`) の意味 |
| 命名規約 | テーブル名・主キー・外部キー・監査カラム・ストアド・トリガーの命名ルール |
| データ型対応 | 論理型 (識別子・文字列・日付等) とRDBMS上の物理型の対応 |
| 共通カラム | 全テーブルに共通して持たせるカラム (`id`・`created_at`・`updated_at`・`deleted_at`等) とその扱い |
| 論理削除・監査方針 | 論理削除の方式、一覧取得時の条件、監査ログの取り方 |
| 文字コード方針 | DBの文字コード・照合順序・タイムゾーン、アプリ側との取り決め |

### 2.2 スキーマ定義

| 項目 | 説明 |
|---|---|
| **データベース情報** | |
| データベース名 / RDBMS / バージョン | 対象データベースとRDBMSの製品名・版 |
| 文字コード / 照合順序 / タイムゾーン | DBの既定の文字コード・並び順の規則・タイムゾーン |
| ストレージエンジン | テーブルの格納方式 (MySQLのInnoDB、PostgreSQLのheap等) |
| マイグレーション管理 | スキーマ変更の管理方法 (マイグレーションツール・ファイルの場所) |
| **スキーマ一覧** | |
| No. / スキーマID | 通番と設計書内のID (`S01`…) |
| スキーマ名 / 論理名 | 物理名と日本語名 |
| 所有者 | スキーマを所有するロール |
| 文字コード / 照合順序 | スキーマ単位の文字コード・照合順序 |
| 概要 | スキーマに置くオブジェクトと役割 |
| **ロール・権限** | ロール名と、そのロールに付与する権限 (SELECT・INSERT・EXECUTE等) と用途 |
| **シーケンス** | シーケンス名と、それを所有 (使用) するテーブル・カラム |
| **拡張機能** | 導入する拡張機能 (PostgreSQLのextension等) と用途 |

## 3. テーブル定義書

先頭に`表紙`・`改訂履歴`を置き、続けて共通仕様 (2.1と同じ) を置く。  

### 3.1 ER図

| 項目 | 説明 |
|---|---|
| データベース情報 | 2.2のデータベース情報と同じ (ER図の前提として再掲) |
| ER図 | テーブル間の関連図 |
| **リレーション一覧** | |
| No. | リレーションの通番 (ER図の線と対応) |
| 親テーブル / 親カラム | 参照される側 (主キー側) のテーブルとカラム |
| 子テーブル / 子カラム | 参照する側 (外部キー側) のテーブルとカラム |
| カーディナリティ | 件数の対応 (`1:1`・`1:N`等) |
| 制約 | `FK`は外部キー制約あり、`論理`は制約はないが業務上関連する |
| 備考 | 関連の意味や補足 |
| 凡例 | ER図中の記号 (PK・FK) と 線種 (実線は外部キー制約あり、破線は論理リレーション) の意味 |

### 3.2 テーブル一覧

| 項目 | 説明 |
|---|---|
| No. / テーブルID | 通番と設計書内のID (`T01`…) |
| スキーマ | テーブルが属するスキーマ |
| 論理テーブル名 / 物理テーブル名 | 日本語名とDB上の名前 (テーブル別シートのシート名は物理名) |
| 種別 | テーブル・ビュー等のオブジェクト種別 |
| サブシステム | テーブルが属する業務領域 |
| 概要 | テーブルで管理する内容 |

### 3.3 テーブル別シート (テーブル・ビューごとに1シート)

**テーブル情報**  

| 項目 | 説明 |
|---|---|
| テーブルID / オブジェクト種別 | テーブル一覧のIDと、テーブルかビューか |
| スキーマ名 / サブシステム名 | 所属スキーマと業務領域 |
| 論理テーブル名 / 物理テーブル名 | 日本語名とDB上の名前 |
| RDBMS | 対象RDBMSと版 |
| 想定レコード件数 | 想定する件数と増加率 (容量見積りの根拠) |
| データ保持期間 | データを保持する期間と保持方法 |
| 個人情報の有無 | 個人情報を含むか、含む場合はどのカラムか |

**テーブルの概要**  
テーブルの役割と、どの処理・画面が登録・参照・更新するか。  

**カラム情報**  

| 項目 | 説明 |
|---|---|
| No. | カラムの定義順 |
| 論理名 / 物理名 | カラムの日本語名とDB上の名前 |
| データ型 | 桁数を含む物理型 (`VARCHAR(100)`等) |
| キー | `PK`は主キー、`FK`は外部キー、`UK`は一意キー |
| Not Null | NOT NULLなら`◯`、NULL可なら`-` |
| デフォルト | 既定値・自動採番の方式 |
| 備考 | 参照先、値の意味、コード値一覧の参照先、個人情報の有無等 |

**インデックス情報**  

| 項目 | 説明 |
|---|---|
| インデックス名 | DB上のインデックス名 |
| カラムリスト | 対象カラム (複合の場合は定義順に列挙) |
| キー | 主キー・一意キー由来のインデックスなら`PK`・`UK` |
| ユニーク | 一意インデックスか (`Yes`・`No`) |
| オプション | 部分インデックスの条件、降順、方式 (btree・gin等) など |

**制約情報**  

| 項目 | 説明 |
|---|---|
| 制約名 | DB上の制約名 |
| 制約タイプ | `PRIMARY KEY`・`UNIQUE`・`CHECK`・`FOREIGN KEY`等 |
| カラム | 制約の対象カラム |
| 制約内容 | 制約の意味<br>CHECKの場合は条件式 |

**外部キー情報**  
このテーブルが他を参照する側  

| 項目 | 説明 |
|---|---|
| 外部キー名 | 外部キー制約名 |
| カラムリスト | このテーブル側の参照カラム |
| 参照先テーブル名 / 参照先カラムリスト | 参照されるテーブルとカラム |
| ON DELETE / ON UPDATE | 参照先が削除・更新されたときの動作 (`RESTRICT`・`CASCADE`・`NO ACTION`等) |

**`外部キー情報(PK側)`**  
他のテーブルからこのテーブルが参照される側  

| 項目 | 説明 |
|---|---|
| 外部キー名 | 参照元テーブルに定義された外部キー制約名 |
| カラムリスト | このテーブル側の被参照カラム |
| 参照元テーブル名 / 参照元カラムリスト | このテーブルを参照しているテーブルとカラム |
| ON DELETE / ON UPDATE | 参照元に定義された削除・更新時の動作 |

**トリガー情報**  
トリガーがあるテーブルのみ  

| 項目 | 説明 |
|---|---|
| トリガーID / トリガー名 | トリガー設定書のIDと物理名 |
| タイミング | `BEFORE`・`AFTER`・`INSTEAD OF` |
| イベント | 起動する操作 (`INSERT`・`UPDATE`・`DELETE`) |
| 単位 | 行ごと (`ROW`) か文ごと (`STATEMENT`) か |
| 概要 | トリガーの処理の要約 (詳細はトリガー設定書) |

**RDBMS固有の情報**  
テーブル空間、FILLFACTOR、自動バキューム、ビューの種別、書込み権限など、そのRDBMS特有の設定を「項目 / 値 / 備考」で記載する。  

**ビュー定義**  
ビューのみ。  
ビューを作成する`CREATE VIEW`文。  
ビューのカラム情報の備考には、元になったテーブルのカラムや計算式を書く。  

### 3.4 コード値一覧

| 項目 | 説明 |
|---|---|
| No. | 通番 |
| コードID / コード名 | 区分のID (`C01`…) と名前 (貸出状態等) |
| コード値 / 内容 | 格納される値とその意味 |
| 使用箇所 | その区分を使うカラム (`テーブル.カラム`) |
| 備考 | 値を設定する処理等の補足 |

## 4. ストアド定義書

先頭に`表紙`・`改訂履歴`を置く。  

### 4.1 ストアド一覧

| 項目 | 説明 |
|---|---|
| No. / ストアドID | 通番と設計書内のID (`R01`…) |
| スキーマ | ストアドが属するスキーマ |
| 論理名 / 物理名 | 日本語名とDB上の名前 (ストアド別シートのシート名は物理名) |
| 種別 | `FUNCTION`・`PROCEDURE` |
| 戻り値型 | ファンクションの戻り値の型 (プロシージャは`-`) |
| 概要 | 処理の要約 |

### 4.2 ストアド別シート (ストアドごとに1シート)

**ストアド情報**  

| 項目 | 説明 |
|---|---|
| ストアドID / 種別 | 一覧のIDとFUNCTION・PROCEDUREの別 |
| スキーマ名 / サブシステム名 | 所属スキーマと業務領域 |
| 論理名 / 物理名 | 日本語名とDB上の名前 |
| 言語 / 戻り値型 | 記述言語 (`plpgsql`・`sql`等) と戻り値の型 |
| 決定性 | 同じ引数で同じ結果を返すか (`IMMUTABLE`・`STABLE`・`VOLATILE`、MySQLでは`DETERMINISTIC`等) |
| SQLデータアクセス | データを読むか書くか (`CONTAINS SQL`・`READS SQL DATA`・`MODIFIES SQL DATA`等) |
| 実行権限 | 実行を許可するロールと付与方法 |
| トランザクション制御 | 内部でCOMMITするか、呼出し元のトランザクションに参加するか |
| 呼出し元 | このストアドを呼ぶバッチ・画面・他のストアド |
| RDBMS | 対象RDBMSと版 |

**ストアドの概要**  
何をするストアドか、誰がいつ呼ぶか。  

**引数**  

| 項目 | 説明 |
|---|---|
| No. | 引数の順番 |
| 引数名 / 論理名 | 物理名と日本語名 |
| 入出力 | `IN`・`OUT`・`INOUT` |
| データ型 | 引数の型 |
| デフォルト | 省略時の値 |
| 備考 | 単位、NULLのときの扱い等 |

**戻り値・結果セット**  
戻り値または返す結果セットの各項目について「項目名 / 論理名 / データ型 / NULL可 / 備考」を書く。  
何も返さない場合は`-`  

**処理内容**  
処理の手順を順番に書く。  
対象 (テーブル・条件) 欄には、操作するテーブル、条件、使用する引数を書く。  

**`参照・更新テーブル (CRUD)`**  

| 項目 | 説明 |
|---|---|
| 物理テーブル名 / 論理テーブル名 | ストアドが操作するテーブル |
| C / R / U / D | 登録・参照・更新・削除 (Create・Read・Update・Delete) を行うなら`○` |
| 備考 | そのテーブルに対して何をするか |

**例外処理**  

| 項目 | 説明 |
|---|---|
| 発生条件 | 例外が起きる状況 |
| SQLSTATE・エラー番号 | 発生するエラーコード |
| 処理内容 | 例外時の動作 (呼出し元への通知・ロールバック・再実行可否等) |

**定義SQL**  
ストアドを作成する`CREATE FUNCTION`・`CREATE PROCEDURE`文の全文  

**呼び出し例**  
実際に呼び出すSQLの例  
`SELECT ...`や`CALL ...`で書く。

## 5. トリガー設定書

先頭に`表紙`・`改訂履歴`を置く。  

### 5.1 トリガー一覧

| 項目 | 説明 |
|---|---|
| No. / トリガーID | 通番と設計書内のID (`TR01`…) |
| 論理名 / 物理名 | 日本語名とDB上の名前 (トリガー別シートのシート名は物理名) |
| 対象テーブル | トリガーを設定するテーブル |
| タイミング / イベント / 単位 | 起動する時点・操作と、行単位か文単位か |
| 概要 | 処理の要約 |

### 5.2 トリガー別シート (トリガーごとに1シート)

**トリガー情報**  

| 項目 | 説明 |
|---|---|
| トリガーID / スキーマ名 | 一覧のIDと所属スキーマ |
| 論理名 / 物理名 | 日本語名とDB上の名前 |
| 対象テーブル | トリガーを設定するテーブル |
| タイミング | `BEFORE`・`AFTER`・`INSTEAD OF` |
| イベント | 起動する操作 (`INSERT`・`UPDATE`・`DELETE`、UPDATE OFの対象列等) |
| 実行単位 | `ROW`は行ごと、`STATEMENT`は文ごと |
| 実行条件 (WHEN) | 起動条件。無条件なら`-` |
| 実行順序 | 同じテーブル・同じ時点に複数ある場合の実行順 |
| 有効状態 | 有効・無効 |
| 実行関数・プロシージャ | トリガーから呼ぶ関数 (PostgreSQLのトリガー関数等) |
| 定義者 | トリガーを作成・所有するロール |
| RDBMS | 対象RDBMSと版 |

**トリガーの概要**  
何のためのトリガーか、どの処理を補うか。  

**処理内容**  
トリガーが行う処理を順番に書く。  
対象 (テーブル・条件) 欄には、操作するテーブルと条件を書く。  

**`参照・更新テーブル (CRUD)`**  
ストアド定義書の4.2と同じ。  
トリガー内で参照・更新するテーブルとC / R / U / Dを書く。  

**例外処理**  
ストアド定義書の4.2と同じ。  
例外が起きたときに元の操作 (登録・更新) がどうなるかも書く。  

**定義SQL**  
トリガー関数とトリガーを作成するSQL (`CREATE FUNCTION`と`CREATE TRIGGER`等) の全文
