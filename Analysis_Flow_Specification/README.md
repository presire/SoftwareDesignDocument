# 解析フロー設計書 項目説明

対象: `[解析フロー設計書]MochDat_DAT解析.xlsx` (見本)  

プログラム / ライブラリが行う解析処理 (ファイル・データの読込と解析) の流れを記載する書類である。  
1冊で1つの解析フローを扱う。  

見本の名称・数値は全て架空の記入例である。  

## シート構成

| シート | 内容 |
|---|---|
| `表紙` | 書類の宛先・名称・作成情報 |
| `改版履歴` | 版ごとの変更記録 |
| `解析概要` | 解析の目的・全体像・前提・入出力・エラー時の扱い・フロー図の凡例 |
| `概要解析フロー図` | 解析処理全体のフロー図と、図中の番号に対応する説明表 |
| `詳細フロー(文字コード判定)` | 概要解析フロー図の定義済み処理を展開した詳細フロー図と説明表 |
| `詳細フロー(行解析)` | 同上 |
| `判定・分岐一覧` | フロー図中の判断 (ひし形) の一覧 |
| `入出力処理設計` | 処理のまとまりごとの処理内容と入出力データ |

| 更新者 / 更新日 | 最終更新の担当者と更新日 |
| シート見出し | シートの題名 |

## 解析概要

| 節 | 説明 |
|---|---|
| 1. 本書の目的 | 対象ライブラリ・解析フローと、本書が記載する範囲 |
| 2. 解析概要 | 処理概要 (何を読み、何を生成するか) と入出力の概要 |
| 3. 前提条件 | 入力の形式・文字コード・サイズ上限・行末・オプション既定値など、解析が前提とする条件 |
| 4. 入出力データ | 解析処理の入力と出力の一覧 (下表) |
| 5. 処理のまとまり | 解析処理を役割ごとに分けた単位と、その役割 |
| 6. 異常終了時処理 | 異常終了時の資源解放・エラー種別への変換・ログ出力の有無 |
| 7. 異常時のリカバリ | 想定されるエラーごとの原因とリカバリ方法 (下表) |
| 8. フロー図 | フロー図のページ一覧と、記号の凡例 (下表) |

4\. 入出力データの列

| 列 | 説明 |
|---|---|
| No | 連番 |
| データ | 入出力データの名称 |
| IN/OUT | 入力か出力かの区別 |
| 形式 | データの形式。該当なしは`-` |
| 文字コード | データの文字コード |
| 受け渡し方法 | 呼出側との受け渡し方法 |

5\. 処理のまとまりの列

| 列 | 説明 |
|---|---|
| No | 連番 |
| 処理のまとまり | まとまりの名称 |
| 役割 | まとまりが担う処理 |

7\. 異常時のリカバリの列

| 列 | 説明 |
|---|---|
| 想定エラー | エラー種別の名称 |
| 原因 | エラーが発生する条件 |
| リカバリ方法 | 利用者または呼出側が取る対処<br>不明な場合は【要確認】 |

8\. フロー図の凡例の列

| 列 | 説明 |
|---|---|
| 記号 | 図形の形状 (楕円・長方形・ひし形など) |
| JIS X 0121名称 | JIS X 0121:1986 / ISO 5807での記号の名称 |
| 用途 | 本書のフロー図での使い方 |

## 概要解析フロー図

解析処理全体のフロー図と、その説明表で構成する。  
図中の赤丸数字は、説明表の番号と対応する。  

| 列 | 説明 |
|---|---|
| 番号 | 赤丸の説明番号<br>判断の番号は判定IDを兼ねる |
| 記号 | 図形の種類 (処理・判断・データ・記憶データ・定義済み処理など) |
| 項目 (図形ラベル) | 図形に書かれた文言 |
| 処理内容 | その図形で行う処理<br>末尾に遷移先を`(次→2)`や`(Yes→4 ／ No→16)`の形で書く |
| 理由・背景 (経緯) | その処理を行う理由や背景 |

## 詳細フロー (文字コード判定 / 行解析)

概要解析フロー図の定義済み処理 (二重縦線長方形) を1ページに展開した詳細フロー図と、その説明表で構成する。  
番号は`<展開元の番号>-<連番>`の形式 (例: `8-1`、`10-1`) とする。  

| 列 | 説明 |
|---|---|
| 番号 | 赤丸の説明番号<br>判断の番号は判定IDを兼ねる |
| 記号 | 図形の種類 (ループ始端 / 終端を含む) |
| 項目 (図形ラベル) | 図形に書かれた文言 |
| 処理内容 | その図形で行う処理と遷移先<br>遷移先には「終了」「エラー終了」もある |
| 経緯・理由・背景 | その処理を行う理由や背景<br>確認が必要な事項は【要確認】と書く |

## 判定・分岐一覧

フロー図中の全ての判断 (ひし形) を一覧にしたものである。  

| 列 | 説明 |
|---|---|
| 判定ID | フロー図の判断の番号 |
| フロー図 | 判断が載っているページ (P1: 概要解析フロー、P2 / P3: 詳細フロー) |
| 判定内容 | 判断の条件 |
| Yesの場合 | 条件を満たすときの遷移先 (番号と図形ラベル) |
| Noの場合 | 条件を満たさないときの遷移先 (番号と図形ラベル) |
| 関連エラー | その判断に関係するエラー種別<br>該当なしは`—` |

## 入出力処理設計

解析処理を初期処理・メイン処理・例外発生時処理・終了処理の順に分け、処理ごとの内容と入出力データを記載する。  

| 列 | 説明 |
|---|---|
| 処理No. | 大分類 (1: 初期処理、2: メイン処理、3: 例外発生時処理、4: 終了処理) と、その中の連番 |
| 開始条件 | 解析処理が開始される契機 |
| 処理内容 | 処理の見出し (対応するフロー図の番号) と具体的な手順・条件・エラー時の扱い |
| IN / OUT | 入力か出力かの区別<br>該当なしは`-` |
| データ | 入出力されるデータ |
| 対応する内部処理 | 解析概要の「処理のまとまり」との対応 |

## 表記

| 表記 | 意味 |
|---|---|
| 【要確認】 | 資料から確認できず、人間の判断が必要な事項 |
| `—` | 該当なし |
| 赤丸数字 | フロー図の図形と説明表の番号を対応付ける説明番号 |
